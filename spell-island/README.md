# 咒语岛 Spell Island

用**声音**指挥小魔法师 Milo 的 3D 英语探索游戏（类塞尔达的第三人称探索）。孩子不点按钮、不用方向键——麦克风一直开着，直接用英语说：

- 走路、跳、跑、转身：`Go to the zookeeper!` `Jump!` `Turn left!` `Run!` `Stop!`
- 和 NPC 交谈、回答他们的问题、帮他们完成任务：`Talk to Tom!` → “Do you like apples?” → `Yes, I do.`
- **念咒语，魔法真的发生**：`Light the lamp!` `Make the pig fly!` `Make the duck yellow!` `Make a cake!` `Eat it!` `Open the door!` `Fly!`（骑扫帚）`Be invisible!` `Grow a tree!` `Make it rain durians!` `Make it snowy!` `Make it winter!` `Heal Tim!`
- **让东西活起来**（1.1 新增）：`Make the panda dance!` `Make the frog jump!` `Make the giraffe sing!` `Make the bear sleep!` `Make the lamp glow!` `Make the horse rainbow!` `Freeze the lion!` / `Melt it!` `Make the zebra disappear!` / `appear!` `Make three ducks!` `Pig, come here!` `Turn the cat into a cake!` / `Turn it back!` `Make the tiger happy!` `Make the elephant giant!` `Make the dog run!`；天空魔法 `Make it night!` `Make it day!` `Make a rainbow!` `Fireworks!` `Make bubbles!`。被施法的人物和小动物会开口回应。
- **更多魔法**（1.3 新增）：`Move the tower to the left!` 挪东西、`Put the pig on a cloud!` 坐云朵、`Make a cloud!` Milo 自己坐云飞、`Make it foggy!` 起雾、`Make it stormy!` 打雷闪电、`Make it rain stars / hearts / flowers / leaves / notes!` 下星星雨、`Make butterflies!` 蝴蝶、`Make a whirlwind!` 旋风、`Shooting stars!` 流星、`Everybody, dance!` 大家一起跳、`Make me big!` 巨人 Milo、`Make the crown gold!` 金属质感、`Make the rabbit invisible!` 半透明隐身；烟花升级为升空再炸开。
- **咒语表**（1.3 新增）：每一课都有一本咒语表，咒语全部用这一课的单词和句型写成（动物课变颜色变动物，天气课起雾打雷，问路课把公交车往左挪，礼貌课说 `Could you please …?`）。左下角卷轴推荐附近能用的咒语，`全部` 打开整本（咒语岛上第一页是十道传送门的地图）。孩子对着念出来就施法并打勾，点一下只是先听读音。每个世界第一次进入时自动翻开一次。
- 连着说也行：`Jump and hit the monkey!`（拿魔杖“咚”地敲一下）`Make a cake and eat it!`
- 说中文时由小伙伴来回答（Milo 只听得懂英语）：想让 Milo 做事，小伙伴告诉你英语怎么说，并给出可点读的提示卡；问问题（“这是哪里？”“熊猫英语怎么说？”）小伙伴用中文回答。

## 内容：10 个课文世界（三年级 ~ 九年级，全部开放，没有锁）

| # | 年级 | 世界 | 主题 / 句型 |
|---|---|---|---|
| 1 | 三上 | Rainbow Zoo 彩虹动物园 | 动物与颜色 · What's this? It's a … |
| 2 | 三下 | Fruit Market 水果魔法集市 | 水果 · Do you like …? Yes, I do. |
| 3 | 四上 | The Flying Classroom 会飞的教室 | 教室物品 · in / on / under |
| 4 | 四下 | Weather Town 天气小镇 | 天气 · What's the weather like? |
| 5 | 五上 | Green Nature Park 绿野自然公园 | 自然 · There is / There are / Is there …? |
| 6 | 五下 | Four Seasons Valley 四季山谷 | 季节 · Which season do you like best? Why? because … |
| 7 | 六上 | Lost & Found Town 迷路小镇 | 问路与出行 · Go straight, turn left · by bus |
| 8 | 七下 | Talent Club Fair 才艺社团节 | 能力 · Can you …? I can … |
| 9 | 八下 | Granny Herb's Hut 药草奶奶的小屋 | 健康 · What's the matter? You should … |
| 10 | 九年级 | The Castle Museum 古堡博物馆 | 礼貌问询 · Could you please tell me where … is? |

每个世界都是**一片可以逛的大地图**（半径约 50 米，室内教室是一座大厅）：6~9 个有名字的区域（走进去会出现地名卡片），20~30 个能施法的东西，5~6 个人物，15~21 个任务，分成 3~4 条故事线可以随时切换。地图按钮能看本世界地图（区域、谁需要帮忙、还没收集的单词星）。

**单词星**：每个世界飘着 16~18 颗金色单词星（粉色的是整句），都是这课的重点单词和句型。走近时会读给你听，大声说出来就收集到；有 2~3 颗藏着，要打开宝箱、天黑后点灯、把大象变小……才会出现。人物和会说话的小动物路过时也会说这课的句子。

任务覆盖**听说读写**：回答 NPC 的问题（说）、听一段话（配 Seedance 生成的动画）选答案（听）、读告示牌回答或朗读（读）、打字写单词/句子（写，开放句子由大模型判断并给中文小提示），还有咒语任务和带路任务。语言难度按年级逐级上升，故事和句子都是原创，只对齐课本话题与句型。

中心是**咒语岛**：Milo 在魔法塔下睡觉，孩子叫醒他后跟着小伙伴学会跳、点灯、让小猪飞、变蛋糕吃掉，然后说 `Go to …` 走进任意一道传送门。

右下角是孩子**自己选的 3D 小伙伴**（猫头鹰咕咕博士 / 小熊猫团团 / 水豚卡皮 / 小火龙焰焰 / 企鹅啾啾），说话时像 Animoji 一样摇头晃脑。孩子卡住时它用苏格拉底式提问一级级引导（先问目标 → 给句子开头 → 二选一 → 示范），时不时提醒“还可以试试这个魔法”。可以点“求助”，也可以关掉。

## 界面

- 风格参考开放世界冒险游戏：深色半透明玻璃面板、发丝级金色描边和角标、青色表示“可交互/进行中”、金色表示奖励，标题用小型大写衬线字（Cinzel）+ 宋体，画面上只留必要信息。
- **麦克风是一个悬浮的水晶球**（实时着色器）：等待时天蓝色云雾缓缓流动，只有孩子自己说话时才轻轻变亮、流动加快；Milo 或小伙伴说话时保持平静。
- **背景音乐**：自己合成的轻柔循环曲（八音盒 + 柔和铺底），咒语岛、户外世界、室内世界各一首；音量很低，有人说话时自动再降低；设置里可以关。生成脚本在资源目录 `music/compose.py`。
- 排版：中文只在标点处换行（实在放不下才断开），短英文句子不拆行；手机上小伙伴的气泡移到顶部，不遮挡对话和提示卡。
- 场景（v1.2）：PBR 光照——太阳实时阴影（跟着 Milo 走）、环境反射、高光泛光（桌面端）、调色与暗角、远景雾；地面、小路、木头、石头的纹理由代码现场生成（不占下载）；小路边缘自然散开；夜晚点亮的路灯会照亮周围。

## 技术

- 前端 Vite + TypeScript + Three.js；后端 Fastify（语音代理 + 大脑），Electron 打包成 Mac App。
- **语音**：豆包 Seed ASR 2.0 流式识别（中英混说）+ Seed-TTS 2.0（每个角色不同音色；固定台词预先合成在 `apps/web/public/voice`）。本地 VAD 判断孩子开口/说完，角色说话时自动静音。
- **大脑**：本地规则大脑（`packages/shared/src/commands.ts`）先解析，零延迟；听不懂的自由说法/中文交给豆包大模型（`doubao-seed-2-1-lite`），输出被校验为合法的动作 JSON 后才执行。NPC 闲聊、开放题判分、小伙伴的引导话术也由大模型生成，失败时都有规则兜底。
- **美术**：方舟 Seedream 5.0 画概念图 → Tripo3D v3.1 生成 PBR 模型；两条腿的角色用 Tripo v3.0 骨骼 + 站立/走/跑/跳动作，站着的四脚动物带骨骼行走（资源目录 `tripo.py`、`quad.py`，key 只放本地 `.tripo-key`；`tools/install_models.py` 安装，WebP 贴图 + meshopt 压缩，174 个模型共约 37MB）；听力动画、传送门动画、标题动画用 Seedance 2.5 生成；App 图标用 Seedream。
- 内容是数据：`tools/make_worlds.py` 生成 `content/`，`pnpm validate` 检查每个世界（引用、任务链、标准答案能否被自己的判分器接受、每句咒语规则大脑能否听懂）。

## 运行

```bash
pnpm install
cp .env.example .env   # 填 DOUBAO_SPEECH_API_KEY，可选 ARK_API_KEY
pnpm dev               # 打开 http://127.0.0.1:5173
```

调试：`?world=rainbow-zoo` 直接进某个世界；控制台 `spell.route("Make the pig fly!")` 模拟说话。

其他命令：`pnpm validate`（检查内容）、`pnpm pregen`（预合成语音）、`pnpm build`。

## 自动更新（腾讯云轻量服务器 games-guangzhou）

- **服务器**：`https://106.55.2.170/spell-island/`（nginx 片段 `/etc/nginx/snippets/spell-island.locations.conf`，已加进 80 和 443 两个 server 块；发布 API 是 systemd 服务 `spell-update`，代码 `/opt/spell-island/`，文件在 `/var/www/spell-island/`）。下载需要 App 令牌（请求头 `X-Spell-App` 或 `?k=`），发布接口每个请求用 HMAC 签名（密钥不在网络上传输，5 分钟内有效，防重放）。服务器端代码和安装脚本在 `tools/update-server/`。
- **热更新**（代码、关卡、语音、模型）：App 启动 8 秒后、之后每 2 小时检查 `latest.json`；只下载变化的文件（按 sha256 去重，没变的文件 Mac 上硬链接、安卓上复制），校验后提示“新内容已就绪 · 立即更新”，点一下原地刷新，进度和设置都保留。Mac 由内置服务器完成（`apps/server/src/updater.ts`），安卓由原生插件完成（`SpellNativePlugin.java`）。
- **安装包更新**（App 外壳变了才需要）：提示“新版本 · 下载安装”。Mac 把 DMG 下到“下载”文件夹并打开；安卓下载 APK 后弹出系统安装界面。装了新安装包后，旧的热更新会自动作废。
- **钥匙**：项目根目录 `.update-key`（`publish` 发布密钥、`app` 下载令牌），不要提交、不要外传；安装包里只有下载令牌。热更新的网页文件里不含任何豆包/方舟 Key（安卓的 Key 在原生层）。

### 发布新版本

```bash
node tools/release.mjs --version 1.0.3 --note "新增……"                 # 只发热更新（大多数情况）
node tools/release.mjs --version 1.1.0 --full --note "……"               # 连同 Mac DMG + 安卓 APK 一起发
# 新网页代码依赖新外壳时加 --min-shell 1.1.0（旧 App 会等安装包更新）
```

每次发布只上传服务器上没有的文件，最后才切换 `latest.json`；旧版本文件自动清理（保留当前和上一版）。

## Android 安装包

`apps/mobile`（Capacitor 7）：`node build.mjs` 生成签名的 `release/咒语岛-1.0.0.apk`。手机上没有本地后端，所以 App 直接调用豆包：语音合成和大模型走 Capacitor 原生 HTTP（无跨域问题），流式语音识别走一个小的原生 WebSocket 插件（`NativeWsPlugin.java`，OkHttp，可以带鉴权请求头）。识别协议、提示词和校验与桌面版共用同一份代码（`packages/shared/src/llmbrain.ts`、`apps/web/src/native/direct.ts`）。Key 在构建时写入；`STRIP_ARK=1` 可去掉大模型 Key。需要 Android SDK 35 + JDK 21。

## Mac 安装包

`apps/desktop`：`node build.mjs` 打包 Electron（内置后端，端口 18788），`make-dmg.sh` 在 Linux 上做 DMG。默认把根目录 `.env` 打进包里（包括方舟 Key）；要发给别人时用 `LUMI_STRIP_ARK=1 node build.mjs` 去掉方舟 Key。
